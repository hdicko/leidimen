Mode Démo

Cette page permet de tester l'interface sans serveur backend. Les données ne seront pas sauvegardées sur GitHub.

Test de l'Interface

Pour tester le CMS complet avec GitHub :

  1. Installer Node.js
  2. Configurer le token GitHub dans .env
  3. Lancer npm start
  4. Ouvrir http://localhost:3000
